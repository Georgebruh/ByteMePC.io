## About the Project

Confused about computer specs and building your own? *Not anymore!*

With **ByteMePC**, you are able to customize your own builds and experiments with a variety of computer parts. **ByteMePC** also shows the compatibility between parts to show whether or not certain parts can be used in tandem with another. If you don't know where to start but have a certain budget, the *Auto-builder* feature will gladly help. Let the AI think up of a list of parts for you, just provide your budget! And if you are interested in any parts and want to save it for later, you can pin parts to use in your own builds. But your own builds aren't the only builds you can see! Take a look at what the community has made and check out what other builders have come up with in their builds.

## Using the Program

### Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

### Project Setup

#### Clone the github repository
```sh
git clone https://github.com/Georgebruh/ByteMePC.io
```

#### Download the dependencies

```sh
npm install
```

#### Compile and Hot-Reload for Development

```sh
npm run dev
```

or Compile and Minify for Production using:

```sh
npm run build
```
